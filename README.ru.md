# Citra

Citra живёт в строке меню macOS. Тащишь файл из Finder, на ходу зажимаешь модификатор, и у курсора появляется круговое меню. Отпускаешь кнопку мыши над сектором, и Citra выполняет это действие над файлом. Главного окна у приложения нет.

| Модификатор | Режим |
|---|---|
| ⌘ | Conversion |
| ⇧ | Tools |
| ⌃ | File Actions |

Если зажато несколько модификаторов, ⌘ важнее ⇧, а ⇧ важнее ⌃. В меню попадают только действия, которые работают для перетаскиваемых файлов. Если их больше 10, видны первые 9 и More, который показывает остальные на дуге снаружи кольца.

## Установка

1. Скачайте `Citra-<версия>.zip` со страницы [Releases](../../releases) и распакуйте.
2. Перетащите `Citra.app` в «Программы».
3. Citra не подписана сертификатом Apple Developer, поэтому с первого раза macOS её не откроет:
   - откройте Citra и закройте появившееся предупреждение;
   - в Системных настройках откройте «Конфиденциальность и безопасность», найдите внизу строку про Citra, нажмите **Всё равно открыть** и подтвердите.

   Можно и одной командой в Терминале. Она же помогает, если macOS пишет, что приложение «повреждено»:

   ```bash
   xattr -dr com.apple.quarantine /Applications/Citra.app
   ```
4. В строке меню появится значок ◎. Начните перетаскивать файл из Finder и только потом зажмите ⌘, ⇧ или ⌃.

Требования: macOS 26 или новее, Apple Silicon или Intel (на Intel не проверялось).

Подписи Apple Developer у приложения нет, поэтому каждое обновление для macOS выглядит как новое приложение, и шаг 3 может понадобиться снова. Кроме того, macOS может отклонить запрос на уведомления, не показав диалог. Тогда включите их вручную: Системные настройки → Уведомления → Citra. Результаты в любом случае появляются рядом с файлами.

## Что умеет

| Тип | ⌘ Conversion | ⇧ Tools |
|---|---|---|
| Изображения (всё, что читает ImageIO: PNG, JPEG, HEIC, TIFF, GIF, BMP, WebP, AVIF…; SVG только на вход) | JPEG, PNG, HEIC, TIFF, AVIF, BMP, WebP (с cwebp), PDF, кроме собственного формата файла | Resize (пресеты), Rotate 90°, Compress (только JPEG/HEIC), Metadata (убрать EXIF/GPS/IPTC/XMP); для SVG ничего |
| ZIP, TAR, TAR.GZ / TGZ | друг в друга (ZIP, TAR, TAR.GZ) | Extract; Test (только ZIP) |
| GZ (одиночный файл) | — | Extract |
| Видео, которое открывает AVFoundation (MP4, MOV, M4V) | MOV ⇄ MP4 (без перекодирования), M4A, GIF; с ffmpeg ещё MKV, WebM, AVI, WMV, MP3 | Compress (720p), Mute, Trim, Crop, Speed, Snapshot |
| Остальное видео (MKV, WebM, AVI, WMV…), нужен ffmpeg | MP4, MOV, MKV, WebM, AVI, WMV, GIF, MP3, кроме собственного формата | — |
| Аудио (MP3, M4A, WAV, FLAC, OGG, Opus, AIFF, WMA…), нужен ffmpeg | MP3, M4A, WAV, FLAC, OGG, Opus, AIFF, WMA, кроме собственного формата | — |
| Субтитры SRT, VTT | SRT ⇄ VTT, TXT (текст без тегов и повторов) | — |
| PDF | — | Merge (2 и больше), Split (по странице в файл) |

⌃ File Actions работают с любыми файлами и папками: AirDrop, Float (плавающая полка), Copy (⌘V в Finder вставляет сами файлы), Move (спрашивает при конфликте имён), Copy Path, Terminal.

Часть действий зависит от системы и внешних инструментов:
- Для HEIC нужен кодировщик ImageIO; на Apple Silicon он есть.
- TAR, TAR.GZ и конвертация архивов работают через `/usr/bin/tar`, одиночный GZ через `/usr/bin/gzip`. Архив, в котором есть пути с `..`, Citra не распаковывает и не конвертирует.
- Для WebP нужен `cwebp` в тех же папках, что и ffmpeg (`brew install webp`): ImageIO умеет WebP только читать.
- SVG растеризуется так, чтобы длинная сторона была не меньше 1024 px.
- OGG кодируется встроенным экспериментальным кодером Vorbis из ffmpeg, потому что в сборке Homebrew нет libvorbis. Звук получается всегда стерео и хуже, чем с libvorbis. Обложка альбома при конвертации аудио не переносится, WAV и AIFF выходят 16-битными.
- Для форматов через ffmpeg нужен `ffmpeg` в `/opt/homebrew/bin` или `/usr/local/bin` с нужными кодировщиками. В приложение ffmpeg не встроен; его статус и подсказку показывает Settings → Conversions.
- Действие Terminal открывает Terminal или iTerm2, смотря что выбрано в настройках и установлено на Mac.
- M4A и Mute показываются даже для видео без звука, а Split даже для одностраничного PDF. До drop Citra файлы не читает, чтобы macOS не запрашивала доступ к папкам. Если такое действие неприменимо, после drop оно объясняет почему и ничего не создаёт.

Результат сохраняется рядом с оригиналом или в выбранную папку. Конвертация меняет расширение (`video.mp4` → `video.mov`), инструмент добавляет слово к имени (`photo rotated.png`), а к занятому имени добавляется номер (`video 2.mov`). Оригинал меняет только Move. Citra пишет во временный файл и переименовывает его по готовности, так что после отмены или ошибки битых файлов не остаётся. Ход задач виден в меню значка ◎, там же их можно отменить.

## Настройки

Строка меню → Settings… (⌘,):
- General: включение, запуск при входе, уведомления, куда сохранять результат.
- Shortcuts: модификатор для каждого режима.
- Appearance: размер кольца, анимации, акцентный цвет.
- Conversions: качество JPEG/HEIC, режим для MOV, доступные конвертации.
- File Actions: Terminal или iTerm2, край полки.

## Сборка

Нужны Xcode 26+ и XcodeGen (`brew install xcodegen`).

```bash
xcodegen generate
xcodebuild -project Citra.xcodeproj -scheme Citra -destination 'platform=macOS' test
xcodebuild -project Citra.xcodeproj -scheme Citra -configuration Debug build
```

Собирайте в стандартный DerivedData и не направляйте `-derivedDataPath` внутрь проекта. Если папку проекта синхронизирует iCloud Drive, codesign отклоняет бандл из-за extended attributes.

По умолчанию сборка подписывается ad-hoc, поэтому собрать проект может кто угодно. Стабильная подпись сохраняет разрешение на уведомления между пересборками, так что, если хотите подписывать свои сборки сертификатом Apple Development, создайте `Config/Signing.local.xcconfig` (git его игнорирует):

```
CODE_SIGN_IDENTITY = Apple Development
DEVELOPMENT_TEAM = <ваш Team ID>
```

## Релиз

```bash
scripts/release.sh
```

Скрипт собирает универсальную (Apple Silicon + Intel) Release-сборку с ad-hoc подписью, проверяет подпись и упаковывает приложение через `ditto` в `dist/Citra-<версия>.zip`. Личный сертификат в релиз не попадает, даже если `Signing.local.xcconfig` существует. Версия задаётся в `project.yml` (`CFBundleShortVersionString`). Опубликовать релиз:

```bash
gh release create v1.0.0 dist/Citra-1.0.0.zip --title "Citra 1.0.0" --notes "…"
```

## Разрешения и sandbox

App Sandbox выключен намеренно. Citra рассчитана на прямое распространение (Developer ID), и ей нужно глобально следить за мышью, записывать результат рядом с оригиналом в любой папке и запускать консольные инструменты вроде `/usr/bin/tar` и внешнего `ffmpeg`.

Разрешения Accessibility, Input Monitoring, Full Disk Access и Automation не нужны. Начало перетаскивания ловит глобальный монитор мыши, модификаторы и Escape Citra узнаёт опросом, а Terminal открывает через Launch Services без AppleScript.

Разрешение на уведомления Citra запрашивает, когда готов первый результат, а не при запуске. Без уведомлений результат всё равно появляется рядом с оригиналом.
