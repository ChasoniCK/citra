## Итог (2026-10-20)

Все пять этапов реализованы и проверены руками в реальном Finder (что именно проверено и как — в разделе каждого этапа). 137 автоматических тестов; Debug и Release собираются без предупреждений. Что умеет приложение и от чего это зависит — в `README.md`. Почему механизм работает и какие у него ограничения — в `docs/feasibility.md`.

**Известные ограничения**
- Мульти-монитор, полноэкранный режим и Spaces не проверены (на этой машине один дисплей).
- До drop тип определяется по расширению и метаданным, а не по содержимому, поэтому файл без расширения получает только File Actions.
- Многокадровые изображения конвертируются по первому кадру. Snapshot — средний кадр. GIF — только первые 15 с. Trim режет по ключевым кадрам.
- Зашифрованные ZIP и PDF не поддерживаются: выдаётся понятная ошибка.
- Полка не сохраняет содержимое между запусками. Дуга More не размыта (только тёмная подложка).
- Для распространения нужна подпись Developer ID и нотаризация. Сейчас сборки подписываются Apple Development. Launch at Login стабильно работает для приложения из `/Applications`.

## Этап 5 — Расширение форматов: закрыт (2026-10-20)

План: `docs/superpowers/plans/2026-10-20-stage5-formats.md`.

### Сделано
- **FFmpeg (не встроен):** MP4 (для MKV/AVI/WebM/WMV), MKV (копирование потоков), WebM (VP9/Opus), AVI (MPEG-4/MP3), WMV (WMV2/WMA2), MP3.
  - Каждый формат доступен, только если найден `ffmpeg` и в нём есть нужные кодировщики (`ffmpeg -encoders` читается один раз при запуске).
  - Запуск — массивом аргументов, без shell. Прогресс берётся из `-progress pipe:1`, длительность — из `ffprobe`. Отмена убивает процесс.
  - Статус и подсказка, как установить, — в Settings → Conversions.
- **MOV → MP4** через AVFoundation — пара к MP4 → MOV.
- **GIF из видео** (AVFoundation + ImageIO): 10 кадров/с, сторона до 480 px, первые 15 с.
- **Видео:**
  - Compress — 720p; если результат не меньше оригинала, он отбрасывается с сообщением.
  - Trim — диалог начала и конца, без перекодирования, поэтому срез попадает на ближайший ключевой кадр.
  - Speed — 0.5× / 1.5× / 2× / 4×, высота звука сохраняется.
  - Crop — центрированные 1:1 / 16:9 / 9:16 / 4:3.
- **PDF:** Merge (2 и больше, в порядке перетаскивания) и Split (по странице в файл, в папку `имя pages`).
- Общий диалог пресетов для Resize, Speed и Crop.

|---|---|

| Разбор времени для Trim, математика Crop (центр, чётные стороны), порядок страниц Merge, файлы Split и ошибка на одностраничном PDF | покрыто тестом (всего 137) |

## Этап 4 — Настройки и системная интеграция: закрыт (2026-10-20)

План и решения: `docs/superpowers/plans/2026-10-20-stage4-settings.md`. Тесты — только для рискованной логики (договорённость с пользователем).

### Сделано
- **Меню в строке меню:** Enabled, Settings… (⌘,), список задач с отменой, Open Log, Quit. Иконка показывает, выключено приложение или занято.
- **Хранилище `AppSettings`:** ключи `UserDefaults` с зарегистрированными значениями по умолчанию; читается и из фоновых задач. SwiftUI связывает те же ключи через `@AppStorage`.
- **Окно Settings, пять вкладок:**
  - General: Enable, Launch at Login (`SMAppService`, кнопка в Login Items, если нужно подтверждение), уведомления с их системным статусом, куда сохранять результат (рядом с оригиналом или в выбранную папку), пояснение, почему разрешения не нужны.
  - Shortcuts: модификатор для каждого режима из ⌘ ⇧ ⌃ ⌥. Выбор занятого — обмен, поэтому дубликат невозможен. При нескольких зажатых приоритет ⌘ > ⇧ > ⌃ > ⌥.
  - Appearance: размер (0.85 / 1 / 1.15), анимации (выкл. / быстрые / обычные), акцентный цвет из 6 пресетов. Применяется со следующего показа кольца.
  - Conversions: качество JPEG и HEIC, пресет для MOV (копирование потоков или перекодирование), какие конвертации доступны на этом Mac.
  - File Actions: Terminal или iTerm2 (если установлен), край, у которого появляется полка.
- Тесты не зависят от настроек пользователя: схема тестов фиксирует нужные значения аргументами запуска.

- Размер кольца: диск и центральная пилюля брали размер из глобального значения, которое SwiftUI не отслеживает, и при смене размера оставались прежними. Теперь размер — явный наблюдаемый параметр.
- Уведомления: macOS спрашивает разрешение один раз за всё время, и первый запрос от ad-hoc-сборки получил отказ. Теперь в General у строки уведомлений есть кнопка для любого состояния («Ask Now» / «Open Notification Settings»), а при выключенных уведомлениях первый результат за запуск предлагает их включить.

## Этап 3 — Типы, реестры, первые операции: закрыт (2026-10-20)

План и решения: `docs/superpowers/plans/2026-10-20-stage3-actions.md`.

### Сделано (в порядке спецификации)
- **Архитектура.**
  - `FileTypeResolver`: тип по сигнатуре содержимого, затем по метаданным, затем по расширению. PNG с расширением `.jpg` — это PNG; более конкретный совместимый тип (DOCX — тоже ZIP) побеждает.
  - Протокол `FileAction` и три реестра в `Registry`; меню собирается только из них.
  - `OutputWriter`: временный файл и атомарное переименование в свободное имя.
  - `TaskManager`: работа вне главного потока, прогресс, отмена, ошибки.
  - Уведомление с кнопкой «Show in Finder»; ход задач и отмена — в меню строки меню.
- **Изображения:** конвертация в JPEG, PNG, HEIC, TIFF и PDF; инструменты Resize (диалог с пресетами), Rotate, Compress (JPEG/HEIC; если результат не меньше — отбрасывается с сообщением), Metadata (без EXIF/GPS/IPTC/XMP, ориентация сохраняется).
- **ZIP.** Свой ридер: stored и DEFLATE, CRC-32, ZIP64.
  - Безопасная распаковка: имена с `..`, абсолютные пути и буквы дисков прерывают всё до первой записи. Симлинки проверяются заранее и создаются последними. `__MACOSX` пропускается. Единственная корневая папка не вкладывается дважды.
  - Test: проверка целостности с сообщением.
  - ZIP → TAR / TAR.GZ: настоящая перепаковка через безопасную распаковку и `/usr/bin/tar`.
- **Видео (AVFoundation):** MP4 → MOV (passthrough, при несовместимости — перекодирование), M4A, Mute (без перекодирования), Snapshot (средний кадр → PNG). Для видео без звука Mute и M4A не предлагаются: дорожки читаются в фоне при начале drag.
- **File Actions:** AirDrop (если недоступен — системное меню «Поделиться»), Float, Copy, Move, Copy Path, Terminal.
  - Float: полка не забирает фокус; перетаскивание из неё — только копирование (оригинал не сдвинуть); ✕ убирает с полки, файл не трогает; полка прилипает к боковому краю.
  - Move: при переносе между томами — сначала копия, удаление исходника только после неё. На конфликт имён — вопрос; Replace отправляет существующий файл в Корзину.
  - Terminal открывается через Launch Services, без shell-строк и AppleScript.

| Что | Как |
|---|---|
| 125 unit- и интеграционных тестов на настоящих файлах, созданных в тестах (изображения — ImageIO, видео — AVAssetWriter с H.264/AAC, ZIP — `/usr/bin/zip` и собранные вручную вредоносные архивы) | покрыто тестом |
| Защита ZIP: `../`, `/abs`, `a/../../x`, `..\x`, `C:/`, симлинк наружу (в том числе внутри корневой папки) — ничего не пишется, ошибка понятна | покрыто тестом |
| Отмена и ошибки не оставляют файлов; папка только для чтения — понятная ошибка; повреждённые файлы — понятная ошибка | покрыто тестом |
| Сценарии A (MP4 → MOV), B (Snapshot), C (Extract), D (PNG → JPEG), F (папка → Copy → ⌘V), I (Float и перетаскивание с полки), E/G/H | проверено руками в GUI; A–D, F, I подтверждены логом и файлами |
| Диалоги Resize и Move, Test для ZIP, Terminal, AirDrop, видео без звука | **не проверено** в GUI (только тестами, где это возможно) |
| Уведомления | в прогоне не работали: «Notifications are not allowed for this application» — приложение было подписано ad-hoc; после перехода на Apple Development **не проверено** |

### Найдено и исправлено по ходу
- В ручном прогоне macOS спросила доступ к папке. Причина — чтение файлов до drop: сигнатура для определения типа и список дорожек видео. Downloads, Desktop и Documents защищены, и чтение без действия пользователя (drop или выбор в диалоге) вызывает запрос; после drop доступ даётся без вопросов. Теперь до drop тип определяется по метаданным и расширению, а по содержимому — уже после drop. Цена: файл без расширения до drop получает только File Actions; Mute и M4A показываются у видео без звука и при drop сообщают «нет аудиодорожки», файлов не создают.
- Сборки подписываются сертификатом Apple Development (Team ID в `project.yml`) вместо ad-hoc: стабильная подпись сохраняет системные разрешения между пересборками и нужна уведомлениям.
- Распознавание «единственной корневой папки» принимало за неё симлинк и убирало его из плана распаковки без проверки. Исправлено, покрыто тестом.
- `ProcessRunner` при отмене сообщал об ошибке инструмента вместо отмены. Исправлено, покрыто тестом.

## Этап 2 — Radial UI по референсам: закрыт (2026-10-20)

План и решения: `docs/superpowers/plans/2026-10-20-stage2-radial-ui.md`.

### Сделано
- Геометрия снята с референсов по профилям яркости (2x-скриншоты): диск 136 pt, сектор 53.5–129.5, прозрачное окно 46, зазор 5, скругления 14 (внешние) и 8 (внутренние), пилюля 84×39. Константы собраны в `RingMetrics`.
- `annularSectorPath` — кольцевой сегмент с параллельными зазорами и точными скруглениями (касание дуг), радиусы скруглений уменьшаются, если сектор узкий.
- Палитра: тёмная (по замерам: сектор ≈ `#2E2E2E`, оранжевый `#FA7349` → `#D44F02`) и светлая.
- Фон: `NSVisualEffectView`, `state = .active` (SwiftUI-материал в неактивном приложении плоский), маска — кольцо без центра.
- Наведение: оранжевый градиент и выдвижение на 4 pt; центр — размер, «Folder», «N items» или подпись действия («PNG → JPEG»).
- Анимации: появление (масштаб + прозрачность), смена режима (кросс-фейд групп секторов), завершение (подсветка выбранного, затухание за 0.2 с), открытие дуги More.
- Больше 10 действий: 9 + **More**; наведение на More открывает наружную дугу с остальными; drop на More ничего не делает.
- Перерисовка: `hovered` меняется только при смене сектора; секторы `Equatable`, перерисовываются только изменившиеся.

## Заметки по окружению
- Проект лежит в `~/Documents`, который синхронизирует iCloud Drive. Из-за этого: (1) сборка в папку проекта падает на codesign (xattr от File Provider) — собирать только в стандартный DerivedData; (2) iCloud уже создавал конфликтную копию `Citra 2.xcodeproj` после `xcodegen generate`. Рекомендация — перенести репозиторий за пределы iCloud.
- XcodeGen установлен через Homebrew (`brew install xcodegen`); после добавления или удаления файлов — `xcodegen generate`.
- Тестовый хост — само приложение: при прогоне тестов в `poc.log` появляется строка `launch:`.
- Логи ручных прогонов 1–3 не в репозитории (временная папка сессии); выводы из них перенесены в `docs/feasibility.md`.
