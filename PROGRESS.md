# Citra — прогресс

Спецификация: `PROMPT.md`. План этапа 1: `docs/superpowers/plans/2026-10-20-stage1-poc.md`.
Результаты по реализуемости: `docs/feasibility.md`.

## Текущий этап: 1 — Proof of concept (прогон 1 пройден, ждёт прогона 2)

### Сделано
- Проект XcodeGen (`project.yml`), menu bar приложение (`LSUIElement`), Swift 6, macOS 15+, без зависимостей.
- `DragMonitor` — начало и конец drag, режим по модификатору, URL из drag-пастборда, Escape через опрос клавиши; без Accessibility и Input Monitoring.
- `RadialMenuPanelController` — одно non-activating `NSPanel`, drop-цель, позиционирование внутри `visibleFrame`; своё состояние показа и приёма drop.
- `RadialLayout` — чистая геометрия и hit-test; `RadialMenuView` — простая отрисовка (стили — этап 2).
- Реальные действия в PoC: ⌘ PNG → JPEG (рядом, атомарно, без перезаписи), ⌃ Copy (file URL на general-пастборд), ⌃ Copy Path. Остальные секторы — тусклые заглушки.
- Диагностика: `~/Library/Logs/Citra/poc.log` (пункт меню «Open PoC Log»), пункт «Experiment: Fade Instead of Order Out».

### Баги прогона 1 (подробно в `docs/feasibility.md`)
1. Кольцо не появляется без движения мыши после нажатия модификатора — причина не найдена (App Nap и задержка детекции исключены); для прогона 2 добавлены диагностика и эксперимент Fade.
2. Кольцо не открывается повторно в том же drag — исправлено (ложная отмена по запоздалому `draggingExited`; ненадёжный `isVisible`).
3. Скрытое кольцо могло принять drop — исправлено, покрыто тестом.

## Заметки по окружению
- Проект лежит в `~/Documents`, который синхронизирует iCloud Drive. Из-за этого: (1) сборка в папку проекта падает на codesign (xattr от File Provider) — собирать только в стандартный DerivedData; (2) iCloud уже создавал конфликтную копию `Citra 2.xcodeproj` после `xcodegen generate`. Рекомендация — перенести репозиторий за пределы iCloud.
- XcodeGen установлен через Homebrew (`brew install xcodegen`); после добавления или удаления файлов — `xcodegen generate`.
- Тестовый хост — само приложение: при прогоне тестов в `poc.log` появляется строка `launch:`.
